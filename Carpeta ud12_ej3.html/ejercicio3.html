Ficha técnica de HTML

Para estructurar una página, HTML utiliza elementos compuestos por etiquetas. Por ejemplo, el elemento <a href="http://www.google.com">Ir a google</a> se utiliza para crear un hipervínculo.

Un desarrollador web puede utilizar atajos de teclado en su editor de código, como Ctrl + S, para guardar sus archivos de trabajo rápidamente.

En la actualidad, la versión más utilizada es HTML5, la cual representó una gran evolución respecto a HTML4, añadiendo nuevas funcionalidades y mejorando el soporte multimedia sin necesidad de plugins externos (como sucedía en la web 1.0 y 2.01).
